Try these PO numbers: PO-2026-0001 (matches your selected factory), PO-2026-0014 (belongs to a different factory — shows the mismatch warning), PO-2026-9999 (not found — shows the API error).

Switching to the real API: open shared/config.js, set useMock: false and put your server in apiBaseUrl. The expected request/response shapes are documented at the top of shared/api.js, and the mappers there accept both camelCase and snake_case field names.

LoginPOST /auth/login → { token, user }
FactoriesGET /factories → { factories: [] }
PO → factory_idGET /pos/lookup?po=… → { factory_id, po }
RecordsGET /pos?factory_id=… → { records: [] }
